AI & Model Methodology

How our deep learning pipeline classifies butterfly images with precision.

🧠

MobileNetV2 Transfer Learning

Leverages a lightweight convolutional neural network pre-trained on ImageNet and fine-tuned for high-accuracy species feature extraction.

📐

224×224 RGB Tensor Normalization

Input images are automatically rescaled and mapped to a normalized floating-point range [-1.0, 1.0] across 3 RGB color channels.

⚡

Asynchronous Inference Engine

Operates on an ONNX Runtime Java engine with a fallback multi-spectral color evaluator to ensure instant execution across all operating environments.
